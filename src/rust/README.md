# Rust engine (`speech`)

The Rust crate (`src/rust/`) is the engine: a Cargo workspace with the core `speech` crate (lib + bin) and the `speech-py` PyO3 binding crate (module `speech_rs`). TOML is the canonical config; a legacy `.config` importer exists for validation runs against goldens. The Python package (`src/python/speech/`) is the optimizer and orchestrator, driving the engine in-process via PyO3.

Build, test and run from `src/rust/` (`cargo build --release`, `cargo test`; the binary is `target/release/speech`); the PyO3 module is built from the repo root with `uv run maturin develop --release --manifest-path src/rust/speech-py/Cargo.toml`. How a run flows through these modules is one page in [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md); the vocabulary is [CONTEXT.md](../../CONTEXT.md); the decisions the layout rests on are the [ADRs](../../docs/adr/); the numbers are in [RESULTS.md](../../RESULTS.md).

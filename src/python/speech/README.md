# Python optimizer and orchestrator (`speech`)

The Python package drives the Rust engine in-process through the PyO3 seam (`speech_rs`): seeded weight init, the gradient-only training loop, the legacy outer search, cost assembly, batching, the DCF/LID evaluation harness, corpus preparation, and the `init`/`train`/`retrain`/`test`/`baseline` CLI. Install with `uv sync --group dev` from the repo root. The lifecycle subcommands (`init`/`train`/`retrain`/`test`/`baseline`) are mounted on `speech.cli:main`; no console script is installed, so that `speech` stays the Rust binary's name, and the baseline arms run as `uv run python -m speech.drivers.baseline <arm> ...`. How a training step flows through these modules is in [docs/ARCHITECTURE.md](../../../docs/ARCHITECTURE.md); the vocabulary is [CONTEXT.md](../../../CONTEXT.md); the decisions are the [ADRs](../../../docs/adr/); the numbers are in [RESULTS.md](../../../RESULTS.md).
